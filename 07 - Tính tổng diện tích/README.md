# 07 - Tính tổng diện tích

**Phiên bản mới nhất:** v1.0.1

Plugin click trực tiếp các Face trong Group/Component để cộng tổng diện tích.

## Chức năng

- Click mặt khi đang đứng ngoài Group/Component.
- Tính đúng khi đối tượng có scale/transform.
- Click lại để bỏ chọn.
- Hiển thị diện tích từng mặt và tổng diện tích.
- Đổi đơn vị m² / cm² / mm².

## v1.0.1

### Cập nhật
- Đổi chữ hiển thị diện tích sang màu đỏ.

- Thêm nền tối phía sau chữ để dễ đọc trên model.

### Sửa lỗi / cải thiện
- Cải thiện khả năng đọc thông tin khi model có nhiều nhãn kích thước.
- Giảm nhầm lẫn giữa số thứ tự mặt và giá trị diện tích.
