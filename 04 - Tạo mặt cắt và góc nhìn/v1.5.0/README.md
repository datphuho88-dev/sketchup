# VADA - Tạo mặt cắt & View v1.5.0

Bản này sửa mapping hướng nhìn để 6 Scene không còn trùng nhau.

- MB: trên.
- VIEW TRẦN: dưới.
- MD1: trước.
- MD2: sau.
- MC1: trái.
- MC2: phải.
- Perspective 35°.
- Mỗi Scene dùng Section Plane riêng và tự đồng bộ khi chuyển Scene.

## Cài đặt

Cài file `VADA_Tao_Mat_Cat_View_v1.5.0.rbz` bằng SketchUp Extension Manager.
