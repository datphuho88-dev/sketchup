# VADA - Tạo mặt cắt & View v1.6.0

## Thay đổi

- Thêm Scene `ALL`.
- Scene ALL nhìn tổng toàn bộ file bằng camera Perspective 35°.
- Scene ALL không tạo và không kích hoạt Section Plane.
- Khi chuyển sang ALL, plugin tự tắt Section Plane đang active.
- ALL luôn căn theo toàn bộ model, kể cả khi đang chọn Group/Component.
- Giữ nguyên 6 Scene mặt cắt: MB, VIEW TRẦN, MD1, MD2, MC1, MC2.

## Cài đặt

Cài file `VADA_Tao_Mat_Cat_View_v1.6.0.rbz` bằng SketchUp Extension Manager.
