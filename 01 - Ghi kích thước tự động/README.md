# 01 - Ghi kích thước tự động

**Phiên bản mới nhất:** v1.1.0

Plugin SketchUp hỗ trợ ghi kích thước nhanh cho các mặt tròn/mặt cong khó bắt điểm.

## Chức năng chính

- Ghi kích thước trực quan trên model.
- Hỗ trợ mặt bàn tròn và hình học khó bắt điểm.
- Giảm thao tác dim thủ công.
- Giao diện tiếng Việt, nền #000000 và hiển thị phiên bản.
- Toolbar/icon rõ ràng khi hiển thị nhỏ.

## Trạng thái phát hành

Kho hiện có README của v1.1.0 nhưng chưa có đầy đủ source + RBZ của bản đã kiểm thử. Không tự tái dựng để tránh khác bản thực tế.
