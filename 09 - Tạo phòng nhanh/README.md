# 09 - Tạo phòng nhanh

**Phiên bản mới nhất:** v1.0.0

Plugin hỗ trợ tạo nhanh một căn phòng trong SketchUp.

## v1.0.0

### Cập nhật
- Phiên bản phát hành đầu tiên.
- Tạo nhanh hình học cơ bản của căn phòng.
- Chuẩn bị cấu trúc source + RBZ để tiếp tục cập nhật theo chuẩn VADA.

### Giao diện
- Tên và nhãn giao diện bằng tiếng Việt.
- Nền giao diện `#000000`.
- Hiển thị rõ mã phiên bản.
- Toolbar dùng icon trực quan, rõ ở kích thước nhỏ.
