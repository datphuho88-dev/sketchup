# VADA Bool Dễ Dùng

Phiên bản mới nhất: **v1.0.1**

## Chức năng
- Gộp khối Solid.
- Trừ khối: A là khối giữ lại, B là khối cắt.
- Cắt giữ dao.
- Lấy phần giao.
- Chia khối.
- Hướng dẫn trực tiếp khi chọn vật thể A/B.
- Kiểm tra Group/Component có phải Solid trước khi chạy.
- Đánh dấu trực quan A/B trong viewport.

## Thay đổi v1.0.1
- Sửa cấu trúc đóng gói RBZ theo chuẩn SketchUp.
- Root RBZ chỉ còn `vada_bool_de_dung.rb` và thư mục `vada_bool_de_dung/` cùng tên.
- Bỏ `manifest.json` khỏi root RBZ.
- Giữ nguyên tính năng của v1.0.0.

## File cài đặt
`VADA_Bool_De_Dung_v1.0.1.rbz`

## Cài đặt
SketchUp → Extension Manager → Install Extension → chọn file RBZ.
Sau khi cài, nếu toolbar chưa xuất hiện, đóng hoàn toàn SketchUp rồi mở lại.
