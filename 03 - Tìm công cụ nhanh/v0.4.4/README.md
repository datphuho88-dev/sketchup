# Tìm Công Cụ Nhanh v0.4.4

Bản sửa lỗi khởi động từ v0.4.3.

- Không còn hiện hộp thoại “Không tìm thấy công cụ gốc” lặp liên tục khi SketchUp mở.
- Không dựng proxy ghim trước khi command gốc của plugin nguồn sẵn sàng.
- Tự quét lại và khôi phục ghim ở các lượt 0,8s / 2,5s / 5s.
- Nếu command gốc vẫn chưa có, ghim đó được bỏ qua âm thầm thay vì mở messagebox.
- Khi bấm một ghim mà công cụ gốc tạm thời chưa sẵn sàng, chỉ báo ở status bar, không mở hộp thoại modal.
- Giữ nguyên icon kết quả tìm kiếm, ghim/gỡ ghim, nhóm, ẩn/hiện nhóm, tên gợi nhớ và phím tắt.

File cài đặt: `tim_cong_cu_nhanh_v0.4.4.rbz`.
