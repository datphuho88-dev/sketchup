# Tìm Công Cụ Nhanh v0.4.3

Giữ nguyên toàn bộ tính năng của v0.4.2 và bổ sung icon trực quan trong kết quả tìm kiếm.

- Hiện icon gốc của UI::Command bên trái mỗi kết quả khi plugin cung cấp icon.
- Hỗ trợ PNG, SVG, JPG/JPEG, GIF, WEBP và BMP.
- Nếu công cụ không có icon hoặc icon không đọc được, hiển thị ô dự phòng bằng ký tự đầu của tên/tên gợi nhớ.
- Icon được cache và giới hạn file preview 64 KB để tránh làm chậm cửa sổ khi có nhiều plugin.
- Giữ nguyên ghim, gỡ ghim, nhóm, ẩn/hiện nhóm, tên gợi nhớ và phím tắt.

File cài đặt: `tim_cong_cu_nhanh_v0.4.3.rbz`.
