# Tìm Công Cụ Nhanh v0.4.6

Bản sửa lỗi tìm kiếm sau v0.4.5.

- Khôi phục tìm kiếm công cụ hoạt động bình thường.
- Chuyển cơ chế gộp kết quả trùng sang Ruby trước khi gửi dữ liệu sang giao diện.
- Không gộp/xóa command trực tiếp ở JavaScript nên không làm mất kết quả tìm kiếm.
- Giữ nguyên icon công cụ, ghim/gỡ ghim, nhóm, ẩn/hiện nhóm, tên gợi nhớ và phím tắt.
- Giữ cơ chế chống hộp thoại “Không tìm thấy công cụ gốc” lặp khi SketchUp khởi động từ v0.4.4.

File cài đặt: `tim_cong_cu_nhanh_v0.4.6.rbz`.

Source đầy đủ nằm trong thư mục `source/`.
