# 03 - Tìm công cụ nhanh

**Phiên bản mới nhất:** v0.4.6

Plugin tìm nhanh lệnh/công cụ SketchUp, hiển thị icon công cụ, đặt tên gợi nhớ, ghim công cụ ra toolbar và quản lý toolbar theo nhóm.

## Chức năng hiện tại

- Tìm nhanh command/tool theo tên.
- Hiển thị icon gốc của công cụ ngay trong kết quả tìm kiếm.
- Tự gộp các kết quả trùng mà không làm mất command tìm kiếm.
- Đặt tên gợi nhớ và hỗ trợ phím tắt.
- Ghim / gỡ ghim.
- Tạo, đổi tên, xóa và phân loại nhóm ghim.
- Ghim/hiện hoặc ẩn riêng từng nhóm toolbar.
- Lưu trạng thái qua lần khởi động.
- Không hiện lặp hộp thoại “Không tìm thấy công cụ gốc” khi extension nguồn chưa load xong.

## Cài đặt

Tải `tim_cong_cu_nhanh_v0.4.6.rbz`, vào **SketchUp → Extension Manager → Install Extension**, sau đó thoát hoàn toàn SketchUp và mở lại.
