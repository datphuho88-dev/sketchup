# 03 - Tìm công cụ nhanh

**Phiên bản mới nhất:** v0.4.2

Plugin tìm nhanh lệnh/công cụ SketchUp, đặt tên gợi nhớ, ghim công cụ ra toolbar và quản lý toolbar theo nhóm.

## Chức năng hiện tại

- Tìm nhanh command/tool theo tên.
- Đặt tên gợi nhớ.
- Ghim công cụ ra toolbar và lưu qua lần khởi động.
- Gỡ ghim.
- Tạo, đổi tên và xóa nhóm ghim.
- Phân loại ghim theo nhóm và tạo toolbar theo nhóm.
- Ghim/hiện hoặc ẩn riêng từng nhóm toolbar mà không xóa công cụ trong nhóm.
- Lưu trạng thái hiện/ẩn từng nhóm và tự khôi phục khi mở lại SketchUp.

## Lịch sử gần nhất

- v0.4.2: thêm ghim/hiện và ẩn độc lập từng nhóm; lưu trạng thái qua lần khởi động.
- v0.4.1: sửa gỡ ghim và quản lý nhóm ổn định hơn.
- v0.4.0: thêm nhóm ghim và toolbar theo nhóm.
- v0.3.3: lưu/khôi phục ghim sau khi khởi động lại SketchUp.

## Cài đặt

Tải file `tim_cong_cu_nhanh_v0.4.2.rbz`, vào **SketchUp → Extension Manager → Install Extension**, chọn file RBZ rồi khởi động lại SketchUp.
