# 03 - Tìm công cụ nhanh

**Phiên bản mới nhất:** v0.4.1

Plugin tìm nhanh lệnh/công cụ SketchUp, đặt tên gợi nhớ và ghim công cụ ra toolbar.

## Chức năng hiện tại

- Tìm nhanh command/tool theo tên.
- Đặt tên gợi nhớ.
- Ghim công cụ ra toolbar và lưu qua lần khởi động.
- Gỡ ghim.
- Tạo, đổi tên và xóa nhóm ghim.
- Phân loại ghim theo nhóm và tạo toolbar theo nhóm.

## Lịch sử gần nhất

- v0.4.1: sửa gỡ ghim và quản lý nhóm ổn định hơn.
- v0.4.0: thêm nhóm ghim và toolbar theo nhóm.
- v0.3.3: lưu/khôi phục ghim sau khi khởi động lại SketchUp.
- v0.3.2: đổi tên hiển thị sang Tìm Công Cụ Nhanh.

> Bản v0.4.1 hiện chưa có file RBZ trong kho.
