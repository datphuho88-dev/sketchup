# VADA Plugin Manager

**Phiên bản mới nhất: v1.5.1**

Plugin trung tâm của VADA để quản lý cài mới, cập nhật, reload, sao lưu, cài lại và gỡ plugin SketchUp.

## Mới ở v1.5.1

- Thêm icon trực tiếp vào danh sách **PLUGIN VADA**.
- Plugin đã cài sẽ lấy icon thật từ loader/thư mục hỗ trợ của plugin.
- Nếu không tìm thấy icon, giao diện dùng ký hiệu `V` dự phòng.
- Chỉ thay đổi phần hiển thị icon; giữ nguyên toàn bộ chức năng v1.5.0: kiểm tra GitHub nền, cache, cập nhật, reload, gỡ plugin, Kho plugin ngoài, bộ lọc, sao lưu và cài nhanh trên PC khác.
- Giao diện nền đen, tiếng Việt, tối ưu cho SketchUp 2023.
