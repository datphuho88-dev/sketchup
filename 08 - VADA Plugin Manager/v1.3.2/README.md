# VADA Plugin Manager v1.3.2

## Sửa lỗi
- Sửa lỗi đóng cửa sổ rồi mở lại bị trắng do tái sử dụng HtmlDialog đã đóng.
- Khi đóng cửa sổ, giải phóng dialog và tạo mới sạch ở lần mở tiếp theo.
- Chỉ gọi JavaScript sau khi HTML báo đã tải xong.
- Tự kiểm tra GitHub sau khi cửa sổ sẵn sàng, không cần bấm Kiểm tra cập nhật lần đầu.
- Bổ sung danh mục offline đầy đủ 01-10, gồm Tạo phòng nhanh và VADA Workspace Manager.
- Tạo phòng nhanh v1.0.0 sẽ hiện ngay cả trước khi quét mạng; sau đó Manager vẫn quét cây GitHub để lấy bản mới nhất.

## Cài đặt
Cài `VADA_Plugin_Manager_v1.3.2.rbz` bằng SketchUp Extension Manager. Vì thay đổi chính Plugin Manager, hãy mở lại SketchUp một lần sau khi cài.
