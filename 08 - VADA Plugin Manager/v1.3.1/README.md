# VADA Plugin Manager v1.3.1

## Sửa lỗi
- Sửa lỗi toolbar/icon không hiện sau khi cài v1.3.0.
- Giữ tham chiếu toolbar trong suốt phiên SketchUp.
- Sau khi SketchUp khởi tạo UI, Plugin Manager tự gọi `show` để hiện toolbar.
- Không tạo trùng menu/toolbar khi reload.
- Giữ nguyên chức năng cài mới, cập nhật, nhận diện phiên bản và hot reload của v1.3.0.

## Gói cài
`VADA_Plugin_Manager_v1.3.1.rbz`

Cài bằng **SketchUp Extension Manager**. Với lần nâng chính Plugin Manager, nên mở lại SketchUp một lần để chắc chắn loader mới được nạp.
