# VADA Plugin Manager v1.3.3

## Sửa lỗi
- Sửa lỗi nhận sai phiên bản đang cài, ví dụ Tạo mặt cắt và góc nhìn v1.6.0 bị đọc thành v1.0.3.
- Ưu tiên khớp chính xác tên SketchUp Extension trước khi dùng nhận diện gần đúng.
- Khi xác định phiên bản máy, đối chiếu đồng thời phiên bản Extension, loader và file core/reload rồi lấy phiên bản hợp lệ cao nhất.
- Bổ sung tên nhận diện `VADA - Tạo mặt cắt View`.
- Giữ toàn bộ sửa lỗi cửa sổ trắng và tự quét GitHub của v1.3.2.

## Cài đặt
Cài `VADA_Plugin_Manager_v1.3.3.rbz` bằng SketchUp Extension Manager, sau đó mở lại SketchUp một lần vì chính Plugin Manager được thay đổi.
