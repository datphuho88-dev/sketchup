# VADA - Click Sâu Mặt Cạnh

**Phiên bản mới nhất:** v1.0.0

Plugin SketchUp cho phép click trực tiếp vào **Face** hoặc **Edge** nằm sâu trong nhiều lớp **Group/Component** mà không cần double-click mở từng cấp.

## Chức năng chính

- Click từ ngoài group/component để bắt Face/Edge sâu bên trong.
- Ưu tiên đối tượng nằm ở đường dẫn lồng sâu nhất tại vị trí con trỏ.
- Hover hiển thị loại đối tượng và số lớp lồng.
- Shift + Click để thêm/bớt lựa chọn.
- Esc để thoát công cụ.
- Toolbar và menu tiếng Việt.
- Hiển thị version ngay trên tên lệnh và hộp giới thiệu.

## Cài đặt

File cài đặt: `VADA_Click_Sau_Mat_Canh_v1.0.0.rbz`

1. Mở SketchUp 2023.
2. Vào **Extension Manager**.
3. Chọn **Install Extension**.
4. Chọn file RBZ ở trên.
5. Nếu toolbar chưa xuất hiện, vào **View > Toolbars** và bật `VADA - Click Sâu`.

## Lưu ý

Công cụ này chọn trực tiếp đối tượng con mà không chuyển SketchUp sang chế độ Edit Group/Component. Việc sửa hình học vẫn tuân theo cơ chế edit context của SketchUp.
