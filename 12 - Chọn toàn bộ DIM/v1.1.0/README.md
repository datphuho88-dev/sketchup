# VADA - Chọn Toàn Bộ DIM v1.1.0

Plugin chọn toàn bộ DIM trong model SketchUp, kể cả DIM nằm trong Group/Component lồng nhiều cấp và DIM do AutoDim tạo.

## Chức năng
- Chọn toàn bộ Dimension native của SketchUp.
- Quét recursive Group/Component lồng nhiều cấp.
- Có tùy chọn nhận diện thêm DIM do AutoDim/AuDim/plugin DIM tạo.
- Hiển thị thống kê số DIM native, AutoDim mở rộng, DIM lồng Group và số context đã quét.
- Giao diện tiếng Việt, nền #000000.
- Hiển thị rõ phiên bản v1.1.0.

## File cài đặt
`VADA_Chon_Toan_Bo_DIM_v1.1.0.rbz`

## Cài đặt
SketchUp → Extension Manager → Install Extension → chọn file RBZ. Sau khi cập nhật nên thoát hoàn toàn SketchUp rồi mở lại.
