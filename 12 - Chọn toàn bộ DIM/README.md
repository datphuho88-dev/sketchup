# VADA - Chọn Toàn Bộ DIM

**Phiên bản mới nhất:** v1.1.0  
**Tương thích mục tiêu:** SketchUp 2023

## Chức năng chính

- Chọn toàn bộ DIM native của SketchUp trong model.
- Quét DIM nằm trong Group và Component lồng nhiều cấp.
- Nhận diện thêm DIM/đối tượng DIM do AutoDim tạo qua tên, Tag/Layer và Attribute Dictionary.
- Có bảng điều khiển riêng để xem thống kê và version.
- Giao diện tiếng Việt, nền #000000.
- Hiển thị rõ phiên bản v1.1.0.

## Lịch sử gần nhất

- v1.1.0: giữ chức năng cũ, tối ưu quét bằng cache và tự làm mới cache khi model thay đổi.
- v1.0.0: phát hành đầu tiên, quét recursive và nhận diện AutoDim mở rộng.

## File cài đặt

`VADA_Chon_Toan_Bo_DIM_v1.1.0.rbz`

## Cài đặt

SketchUp → Extension Manager → Install Extension → chọn file RBZ. Sau khi cập nhật nên thoát hoàn toàn SketchUp rồi mở lại.
