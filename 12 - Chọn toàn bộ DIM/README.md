# VADA - Chọn Toàn Bộ DIM

**Phiên bản mới nhất:** v1.0.0  
**Tương thích mục tiêu:** SketchUp 2023

## Chức năng chính

- Chọn toàn bộ DIM native của SketchUp trong model.
- Quét DIM nằm trong Group và Component lồng nhiều cấp.
- Nhận diện thêm DIM/đối tượng DIM do AutoDim tạo thông qua tên Group/Component, Tag/Layer, Attribute Dictionary và các dấu hiệu AutoDim / AuDim / DIM / Dimensions / Kích thước.
- Bấm icon toolbar là chọn ngay toàn bộ DIM.
- Có bảng điều khiển riêng trong menu Extensions để xem thống kê và version.
- Giao diện tiếng Việt, nền #000000.
- Hiển thị rõ phiên bản v1.0.0.

## Thay đổi v1.0.0

- Phát hành đầu tiên.
- Thêm quét recursive toàn bộ Group/Component.
- Thêm deep selection cho DIM nằm ngoài active context.
- Thêm nhận diện AutoDim mở rộng.
- Thêm giao diện thống kê số DIM đã chọn.

## Cài đặt

1. Mở SketchUp 2023.
2. Vào Window > Extension Manager.
3. Chọn Install Extension.
4. Chọn file VADA_Chon_Toan_Bo_DIM_v1.0.0.rbz.
5. Sau khi cài, mở toolbar VADA - Chọn DIM hoặc vào Extensions > VADA - Chọn Toàn Bộ DIM.

## Lưu ý

Plugin chỉ quét/chọn đối tượng, không tự Move/Rotate hình học xuyên nhiều context. Với thay đổi extension/toolbar, nếu SketchUp không nạp sạch sau khi cài hoặc cập nhật thì thoát hoàn toàn SketchUp rồi mở lại.
