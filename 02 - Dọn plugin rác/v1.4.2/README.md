# Dọn Plugin VADA v1.4.2

## Sửa lỗi

- Sửa lỗi đóng gói v1.4.1 khiến file RBZ trên GitHub không cài được trong SketchUp.
- RBZ v1.4.2 được đóng gói lại đúng cấu trúc: loader ở gốc và thư mục `vada_extension_cleaner/` đầy đủ.
- Giữ nguyên chức năng **Thử hiển thị** đã sửa ở v1.4.1.

## File cài

- `VADA_Don_Plugin_v1.4.2.rbz`

## Cài đặt

SketchUp → Extension Manager → Install Extension → chọn file RBZ. Sau khi cập nhật nên thoát hoàn toàn SketchUp rồi mở lại.
