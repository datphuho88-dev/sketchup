# 06 - Thống kê sắt hộp

**Phiên bản mới nhất:** v1.1.1

Plugin thống kê sắt hộp trong model SketchUp theo tiết diện và chiều dài, đồng thời hỗ trợ nhận diện trực quan trên mô hình.

## Chức năng

- Gom nhóm theo kích thước tiết diện.
- Tính tổng chiều dài theo từng loại hộp.
- Thống kê số lượng theo chiều dài/cấu kiện.
- Tô màu phân biệt các tiết diện khác nhau trên model.
- Bản v1.1.1 cải thiện nhận diện và tô màu các hộp còn bị bỏ sót.
