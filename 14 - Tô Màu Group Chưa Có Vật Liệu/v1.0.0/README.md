# VADA - Tô Màu Group Chưa Có Vật Liệu

**Phiên bản mới nhất:** v1.0.0

## Chức năng chính

- Quét toàn bộ Group trong model, bao gồm Group lồng nhau.
- Chỉ xử lý Group chưa được gán vật liệu ở cấp Group.
- Mỗi Group được gán một màu khác nhau để dễ nhận biết.
- Không thay đổi Group đã có vật liệu.
- Không tạo timer/observer chạy nền.
- Toàn bộ thao tác nằm trong một SketchUp Operation nên có thể Undo bằng `Ctrl+Z`.

## File cài đặt

`VADA_To_Mau_Group_v1.0.0.rbz`

## Cài đặt

1. Mở SketchUp 2023.
2. Vào **Extensions > Extension Manager**.
3. Chọn **Install Extension**.
4. Chọn file `VADA_To_Mau_Group_v1.0.0.rbz`.
5. Sau khi cài, mở từ toolbar **VADA - Tô Màu Group** hoặc menu **Extensions**.

## Thay đổi v1.0.0

- Bản phát hành đầu tiên.
- Giao diện tiếng Việt, nền `#000000`.
- Hiển thị version trực tiếp trên cửa sổ plugin.
