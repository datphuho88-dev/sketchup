# VADA Workspace Manager

**Phiên bản mới nhất: v1.0.0**

Quản lý và tự dọn toolbar SketchUp để cài thêm plugin không làm rác màn hình mỗi lần khởi động.

## Chức năng chính
- Lưu profile toolbar đang hiện/ẩn.
- Quản lý toolbar plugin VADA và plugin bên ngoài qua `UI::Toolbar`.
- Tùy chọn quản lý cả toolbar gốc SketchUp.
- Tự dọn sau `onExtensionsLoaded`, kèm vài lượt kiểm tra ngắn.
- Phát hiện toolbar mới, đánh dấu `MỚI`.
- Nhiều profile workspace.
- Dọn nhanh và hoàn tác.
- Không chạy polling nền liên tục.

## Cài đặt
Cài file `VADA_Workspace_Manager_v1.0.0.rbz` bằng **Extension Manager**.

## Cách dùng lần đầu
1. Sắp xếp và đóng/mở toolbar đúng ý.
2. Mở `Extensions > VADA Workspace Manager`.
3. Bấm **LƯU MÀN HÌNH HIỆN TẠI**.
4. Giữ bật **Tự dọn khi mở SketchUp**.
