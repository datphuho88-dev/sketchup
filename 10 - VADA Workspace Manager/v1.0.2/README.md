# VADA Workspace Manager v1.0.2

Quản lý và tự dọn toolbar SketchUp.

## Mới ở v1.0.2
- Thêm ô **Tìm nhanh toolbar / plugin** theo tên.
- Thêm bộ lọc: **TẤT CẢ / ĐANG HIỆN / ĐANG ẨN / MỚI / GIỮ**.
- Toolbar đang hiện luôn được đưa lên đầu danh sách, không phải cuộn xuống tìm.
- Bộ lọc áp dụng đồng thời cho toolbar plugin và toolbar gốc SketchUp.
- Hiển thị số kết quả đang lọc trên tổng số toolbar.
- Phím `/` đưa con trỏ vào ô tìm kiếm; `Esc` xóa tìm kiếm.
- Giữ nguyên trạng thái các ô **GIỮ** khi tìm kiếm/lọc.

## Chức năng chính
- Ẩn/hiện trực tiếp `UI::Toolbar`.
- Dọn nhanh toolbar plugin, trừ toolbar chọn **GIỮ**.
- Lưu và áp dụng profile workspace.
- Hoàn tác lần dọn gần nhất.
- Tự dọn nhiều lượt sau khi SketchUp load extension.
- Không uninstall hoặc disable plugin.

## Cài đặt
Cài `VADA_Workspace_Manager_v1.0.2.rbz` bằng **SketchUp Extension Manager**.

Sau khi cài bản mới, nên thoát hoàn toàn SketchUp rồi mở lại để loader và UI dùng đúng v1.0.2.
